# 01 产品需求与定义

状态：**待用户确认**

## 1. 产品定位

LabSafe 是面向高校化学实验室的智能辅助巡检平台，将现场图像中的可观测事实转化为可复核、可派发、可复查的整改任务。系统不替代安全员，不对无法从图像可靠判断的事项给出确定结论。

## 2. 目标用户与职责

| 角色 | 主要职责 |
|---|---|
| 安全管理员 | 管理实验室、用户、模板、规则、报表和全局任务 |
| 实验室负责人 | 查看本实验室风险，确认责任人和整改期限 |
| 安全员/巡检员 | 采集照片、复核 AI 结果、执行复查 |
| 整改责任人 | 接收任务、提交整改说明和复查材料 |
| 只读查看者 | 查看被授权的记录和报表，不可修改 |

## 3. 核心用户流程

```text
选择实验室与模板
  -> 按模板拍摄/上传
  -> 图像质量检查
  -> 目标检测、OCR、实体标准化
  -> 相容性规则检查
  -> 安全员逐项复核
  -> 形成待派发问题
  -> 管理者分派责任人与期限
  -> 责任人整改并提交材料
  -> 安全员复查
  -> 销项或驳回
  -> 统计、导出和困难样本沉淀
```

## 4. MVP功能

### 4.1 实验室与模板

- 实验室、区域/房间、货架/柜号、责任人维护。
- 巡检模板按检查项规定拍摄目的、示例和补拍提示。
- 首期位置粒度为实验室 -> 区域/房间 -> 货架/柜号 -> 图片中的相对位置。

### 4.2 巡检采集

- 响应式 Web 兼容手机和桌面浏览器。
- 按模板逐项拍摄；支持补拍、批量上传和任务草稿。
- 记录采集人、时间、实验室、区域/柜号和客户端信息。
- 图片质量失败时必须显示具体原因并要求补拍。

### 4.3 AI识别

- 图像质量：模糊、过暗、反光、严重遮挡。
- 目标：试剂瓶、标签区域、人员、护目镜、实验服、同柜相邻容器。
- OCR：试剂名称、浓度、日期、危险标识均尝试提取；首期只有名称和日期进入风险结论。
- 实体标准化：商品名/缩写/中英文名映射到内部化学品实体；低置信度必须人工确认。
- 相容性：仅对同一货架/柜内可见相邻存放进行规则检查。
- 首期不将大语言模型放入安全识别主链；预留独立旁路扩展接口。

### 4.4 人工复核

- 每个问题独立复核，可确认、修改、驳回或标记“无法判断”。
- OCR 无法标准化时允许人工录入；确认前不得执行相容性结论。
- 所有操作记录操作人、时间、旧值、新值和原因。

### 4.5 整改闭环

状态机：`待派发 -> 处理中 -> 待复查 -> 已销项`，并支持 `逾期`、`驳回`、`无法整改`。

- AI/安全员确认后先生成“待派发问题”，管理者再指定责任人和期限。
- 期限由管理者按风险等级设置，支持个别调整并留痕。
- 责任人上传整改说明和照片后进入待复查。
- 只有安全员确认复查证据后才能销项。

### 4.6 报表

- 按实验室、时间、问题类型、严重度和整改状态统计。
- 导出 CSV/PDF，带图片/问题/规则/模型版本索引。
- 展示高风险问题召回率、误报类型、整改按期率和重复问题趋势。

## 5. 明确不属于MVP

视频流持续识别、PPE 和安全设施识别、温湿度/气体/门禁传感器、自动库存盘点、完整边缘端离线推理、气体泄漏识别、化学品真实成分推断、设备内部故障识别、复杂实验操作规范判断。

## 6. 非功能要求

- 校内单服务器部署，真实试点要求在断公网但校内局域网可用时仍能处理新上传图片。
- 图像质量结果秒级返回；完整 AI 结果目标不超过 30 秒，超时进入异步处理中。
- 所有 AI 结论保存原图、裁剪图/框、字段置信度、规则版本、模型版本和人工操作记录。
- 首期采用本地账号与固定角色，预留统一身份认证接口。
