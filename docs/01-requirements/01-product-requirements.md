# 01.1 产品需求

## 用户和责任

安全管理员配置组织、权限、版本和发布；实验室负责人查看/派发本实验室问题；安全员采集、复核、独立复查；整改责任人接单和提交证据；viewer只读；规则专家独立审批规则。管理员不自动获得代替受派人提交/自我复查的特权。

## 核心闭环

选择实验室和已发布模板 → 按位置采集1–3图 → 质量检查/补拍 → AI事实 → 确定规则候选 → 人工复核 → 派发/接单 → 整改证据 → 独立复查 → 销项和报告。无法判断与技术失败必须可区分，历史版本和证据必须可追溯。

## 首期AI范围

质量（模糊、亮度、过曝）、瓶/标签/柜检测、名称和明确日期OCR、冻结词典实体候选、同图可见容器关系；不含视频、在线LLM、自动最终风险定性或跨图几何拼接。首期模型适配和业务指标缺口见 [解决方案](../08-delivery/04-remediation-plan.md)。

## 成功标准

可完成闭环、阻止越权和绕人工确认、失败可恢复、固定版本可追溯；真实准确率/召回和规则有效性必须另经专家数据验证。系统不替代实验室安全责任人。
