# 06 AI、数据与规则规范

状态：**待用户确认**

## 1. 数据范围

- 现场实验台、试剂柜、安全设施和标签图片。
- 标签局部图、文字原文、字段结构化值和字段置信度。
- 化学品标准名称、别名、CAS/内部编号、危险类别和存储要求。
- 人工确认、驳回、无法判断、整改和复查结果。

## 2. 采集规范

- 按模板逐项拍摄，记录实验室、区域/柜号、拍摄时间和采集人。
- 每个检查项提供远景证据和必要的局部标签补拍。
- 禁止同一场景连拍跨训练/验证/测试集合。
- 图片原始文件保留哈希、尺寸、方向和压缩信息。
- 采集前完成校方授权；训练前对非必要人脸自动打码或裁剪。

## 3. 标注规范

- 目标框：试剂瓶、标签、人员、护目镜、实验服、柜/货架、相邻容器。
- OCR：文字框、原文、标准化字段、字段缺失原因。
- 风险：`risk`、`safe_observed`、`cannot_determine` 三态，不得把缺图当安全。
- 分歧由安全专家裁决，保存标注者意见、裁决人和依据。
- 建立 300～500 个包含反光、遮挡、小目标或模糊的困难样本池。

## 4. 模型流水线

```text
质量检测 -> 目标检测 -> 标签裁剪/透视校正 -> OCR
-> 字段抽取 -> 化学品实体标准化 -> 相邻关系构建
-> 相容性规则 -> 严重度建议 -> 人工复核
```

首期每个模块固定一个可复现基线；只有指标或部署约束明确不满足时才替换。候选技术包括 YOLO/RT-DETR、PaddleOCR 和常规图像增强。受 20 天周期限制，评测采用“最小基线集 -> 临时迭代门槛 -> 候选验收集”的分阶段方案；样本量和正式门槛在评测集冻结时记录。

## 5. 化学品标准化

- 别名、中文名、英文名、缩写和商品名映射到内部实体。
- 映射保存来源、置信度、匹配方式和人工确认状态。
- 低置信度或多个候选时进入待确认，不执行相容性结论。

## 6. 规则模型

- 规则由安全管理部门批准，采用版本化发布。
- 首期至少覆盖 20 条专家确认规则。
- 规则主粒度为危险类别/化学品类别矩阵，必要时支持具体 CAS 例外。
- 只有在同一货架/柜内具有可见相邻关系时触发混放检查。
- 输出规则 ID、版本、输入事实、触发条件、解释、建议动作和人工复核要求。
- 大模型不得直接生成最终安全结论。

## 7. 训练与评测

- 按实验室、采集批次和场景分组切分 70/15/15；测试集冻结后不回流训练。
- 检测报告 mAP、召回率；OCR 报告字符和字段准确率；风险报告高风险召回率、误报率和无法判断率。
- 真实现场数据为主要验证/测试数据；合成增强仅用于训练增强。
- 模型版本、阈值、数据集版本和代码提交号必须写入 InferenceRun。
