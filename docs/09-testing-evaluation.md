# 09 测试、评测与质量门禁

状态：**待用户确认**

## 1. 测试层级

- 单元测试：领域状态机、权限、规则匹配、字段标准化、数据校验。
- 契约测试：前端与 API、业务服务与推理服务、队列消息和对象存储。
- 集成测试：上传 -> 推理 -> 复核 -> 派发 -> 整改 -> 复查 -> 销项。
- 模型测试：质量、检测、OCR、标准化、相容性和端到端风险。
- 非功能测试：性能、并发、失败重试、断网、权限越权、备份恢复。
- 可用性测试：安全员完成一次巡检的步骤数、误操作和任务完成时间。

## 2. 质量门禁

### 代码门禁

- 主分支构建、迁移、单元测试和静态检查通过。
- 禁止未审计的直接状态更新接口。
- 关键领域逻辑覆盖正常、边界和拒绝路径。

### 模型门禁

- 测试集版本冻结，数据来源和切分可追溯。
- 高风险召回率按问题类别报告；未达门槛必须进入风险清单。
- 无法判断率、人工驳回率和误报类型同时报告，不能只看单一指标。

### 发布门禁

- 新版本通过回归集、权限测试、备份恢复和回滚演练。
- 规则/模型版本可在 UI 和审计记录中查询。
- 试点用户完成培训，Demo 数据和真实数据明确隔离。

## 3. 对照实验

在两个实验室安排不同验证方式：一个实验室进行人工巡检与 LabSafe 辅助巡检的现场对照；另一个实验室进行历史数据回放。记录耗时、发现问题数、误报、漏报、整改按期率、复查完成率和用户反馈。算法离线指标与业务现场指标分开报告。

## 4. 断网验收脚本

预置数据、模型、规则和账号；断开公网后完成登录、选择实验室、上传预置照片、等待推理、人工确认、派发、提交复查照片、销项和导出报告。任何外部 CDN、云 API 或在线字体依赖都必须被清除或本地化。
