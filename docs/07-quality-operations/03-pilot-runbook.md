# 07.3 试点运行清单

## 1. 开始条件

管理员、实验室负责人、采集复查人员和整改人员已明确；真实模型/词典/规则有来源、许可和审批；验收指标在评测前签署；工程、安全、恢复和断公网测试通过。未完成不得以“设计校验PASS”代替。

## 2. 一次试点

1. 冻结代码、模型、字典、规则、数据、硬件清单和activation。
2. 至少一个实验室现场采集及另一个实验室历史回放；按授权采集，记录未知与失败，不挑选只成功样本。
3. 专家先独立标注，再与系统对比；记录漏报/误报、OCR实体错误、质量拒绝、人工耗时、流程失败。
4. 跑通派发、整改、独立复查、无法整改及导出；确认没有把无法判断显示为安全。
5. 汇总批准指标与实际值、样本数量及置信区间、设备与版本、全部偏差；专家和实验室负责人签署结论。

## 3. 停止和恢复

重大漏报、错误规则、越权、证据损坏或恢复失败立即暂停受影响流程，保全原版本与审计；禁止删除失败样本重算成绩。纠正后用冻结回归集复验，必要时重新审批。未达标结论记为未通过，不做带条件上线承诺。
